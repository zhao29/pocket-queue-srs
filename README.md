# pocket-queue-srs
Dynamic spaced repetition scheduler using M/G/1 queueing model with daily regression for service rate μ. Supports parallel decks experiment (Deck A: standard Anki SM2; Deck B: custom load control) to prevent card avalanches.

基于M/G/1排队模型的动态间隔重复调度器，每日回归估计μ，支持平行双组实验（Deck A: 标准Anki SM2；Deck B: 自定义负载控制），有效打败卡片雪崩。
